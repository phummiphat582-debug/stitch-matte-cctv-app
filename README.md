# Stitch Matte CCTV Field Survey UI

เว็บแอพ static SPA สำหรับทำแปลนสำรวจ CCTV จาก `stitch_matte_monochrome_ui_design.zip` โดยเริ่มต้นเป็นข้อมูลว่าง ไม่มีข้อมูลเดโม่

## เปิดใช้งาน

เปิด `index.html` ด้วยเบราว์เซอร์ได้โดยตรง หรือรัน static server เช่น:

```powershell
python -m http.server 4173 --directory .
```

จากนั้นเปิด `http://localhost:4173/`

## Workflow หลัก

1. เปิดหน้า `แปลนสำรวจ`
2. กด `อัปโหลดแปลน` แล้วเลือกไฟล์ PNG/JPG/WebP ของแปลนที่มีอยู่
3. กดปุ่ม `เพิ่มกล้อง` แล้วคลิกตำแหน่งบนภาพแปลน
4. กรอกรหัส/รุ่น/หมายเหตุ และแนบภาพจริงจากเครื่อง
5. กดบันทึก แล้วคลิกหมุดเดิมเพื่อเปิดภาพจริงของจุดนั้นแบบ modal

ข้อมูลแปลน, จุด, พิกัด และภาพที่แนบถูกเก็บใน `localStorage` ของเบราว์เซอร์เครื่องนั้น จึงไม่ปะปนกับข้อมูลเดโม่และใช้งานออฟไลน์ได้ หากต้องการให้หลายคนเห็นข้อมูลชุดเดียวกัน ต้องเชื่อมฐานข้อมูลกลาง เช่น Firebase หรือ Supabase เพิ่มภายหลัง

## หน้าจอที่รวมไว้

- แปลนสำรวจ: floor plan canvas, marker, FOV, zoom และรายละเอียด CAM-01
- อุปกรณ์: search, status/type filters, summary และรายการจุดที่ผู้ใช้เพิ่มเอง
- รายละเอียดอุปกรณ์: เปลี่ยนสถานะ, แก้ไขรายละเอียด และแนบภาพจริง
- สรุป/ส่งออก: blueprint preview, CSV export และสรุปภาพจริง
